FORGOTTEN ISLAND WEBSITE
Team: THE ISLAND KEEPERS
PROJECT DESCRIPTION
A cinematic and responsive movie promotional website inspired by DreamWorks'
Forgotten Island. The website features movie information, character introductions,
and a merchandise page with an interactive shopping cart.
